# Project Bane

Daily training, nutrition, and progress web application.

## Foundation

- Dashboard focused on today's actions and progress
- Printable daily workout sheets for use away from the app
- Workout completion and actual-performance logging
- Nutrition and bodyweight tracking
- Canonical source document import/synchronization
- GitHub as the long-term source repository
- Manual uploads as a fallback

Project Bane is designed to minimize daily data entry while preserving a complete year-long training history.
